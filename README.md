💻 TechCode

Projeto de desenvolvimento web utilizando exclusivamente HTML5.

O TechCode é um projeto acadêmico desenvolvido para praticar os principais recursos da linguagem HTML5, criando um site com múltiplas páginas e navegação entre elas.

O projeto foi desenvolvido sem CSS e sem JavaScript, utilizando apenas HTML.

⸻

📌 Sobre o projeto

O site simula uma plataforma de tecnologia e programação, apresentando conteúdos sobre cursos, projetos, programação e formas de contato.

O objetivo principal é colocar em prática conceitos fundamentais de desenvolvimento web, como:

* Estrutura de páginas HTML
* Links e navegação
* Imagens
* Vídeos
* Tabelas
* Formulários
* Listas
* Áudio
* Iframes
* Cabeçalhos
* Rodapés
* Seções
* Artigos
* Elementos semânticos

⸻

🌐 Páginas do projeto

O projeto possui 5 páginas navegáveis:

Página	Descrição
🏠 index.html	Página inicial
👨‍💻 sobre.html	Informações sobre o projeto
📚 cursos.html	Cursos disponíveis
🚀 projetos.html	Projetos desenvolvidos
📩 contato.html	Formulário de contato

Todas as páginas possuem um menu de navegação que permite acessar as demais partes do site.
